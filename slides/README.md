# Slides

`mdln_synthetic_data.tex` — *Leveraging AI and Synthetic Data in TAF-based Research*
Medicaid Data Learning Network, 15 September 2026.

Build:

```bash
pdflatex mdln_synthetic_data.tex
```

Two compiles if you want the PDF outline links resolved. No bibliography, no
external figures — both diagrams are TikZ, so the file is self-contained.

The deck uses the `notes` class option, so `\note{...}` blocks are available if
you want speaker notes on a second screen.
